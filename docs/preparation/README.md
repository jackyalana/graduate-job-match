# 毕业生就业推荐与岗位匹配系统开发准备包

课题：基于 Spring Boot + Vue 的毕业生就业推荐与岗位匹配系统。

日期：2026 年 10 月 27 日。状态：已完成网上选型、候选源码抽查与开发规格；尚未安装、编译、启动或验收候选系统。

建议优先复用 Lan-Recruitment 的基础业务和 Vue 3 页面，独立完成毕业生画像、可解释匹配、冷启动策略、流程完善及评估。复用准入以 M0 的实机结果为准，不能将本准备包当作已有可运行系统。

## 使用方式

1. 将整个文件夹交给实施 AI，发送 `docs/03-implementation-prompt.md` 的完整内容。
2. 实施 AI 在独立项目目录工作，先锁定上游提交并完成 M0 原项目启动与复用审计。
3. 将 M0 报告和代码路径或 GitHub 仓库链接交回当前审核聊天。此时审核者检查实际提交、日志与页面，决定通过或返工。
4. 每个里程碑都按同样方式交付。没有可读取代码或运行证据时，只能审核文档，不能给出“系统已通过”结论。

未预设学校模板、截止日期及导师对开源二次开发和 AI 辅助的要求。默认是本科单人毕设、允许注明来源的开源复用、本地答辩演示。若学校要求全原创，应在复制业务源码前切换到独立实现路线，保留通用开源依赖和出处说明。

本包是开发规格，不是论文成稿，不包含虚构实验结果。SDD 指 Software Design Description，同时承担按规格开发的实施基线。
