# ADR-0002：M1 会话、附件与数据迁移边界

状态：M1 已实施，待审核。上游 AGENTS 中仅 GET/POST、禁止外键以及仅控制器鉴权等与本课题 SDD 冲突时，以用户明确提供的新 SDD 和 M1 指令为准。没有升级框架。

## 会话

Sa-Token 令牌仅从 `satoken` 请求头读取，cookie/body 读取关闭；Vue localStorage 保存令牌，Axios `withCredentials=false`。默认 CORS 来源仅 127.0.0.1:15173、127.0.0.1:15174、localhost:5173，可通过 `lan.cors.origins` 明确配置；不允许任意来源或跨站凭证。每个受保护 API 检查登录和数据库账号启用状态，HR 还要求审核通过；停用时立即注销该账号的令牌。`/api/common/**` 面向三角色，仍需账号有效；user/student、hr、admin 各自检查角色。

这是单实例、本机演示的 header 令牌方案；localStorage 一旦发生 XSS 可能暴露令牌，线上环境还需 HTTPS、XSS 防护、限流与完整安全审查。内存密码及邮箱登录限流为直接客户端地址+账号在60秒内5次失败，状态在服务重启后丢失；多实例、代理地址信任和分布式限流未验证。

`demo` profile 且 `lan.demo.local-registration=true` 且请求源为本机时允许合成注册，邮箱未验证；正常配置仍需真实邮箱验证码，不能用固定通用码。demo profile 应仅绑定 loopback，不应通过代理公开。前端也明确显示合成演示和未验证邮箱。生产邮箱验证与真实 SMTP 本次未测试。

## 附件

删除 `/uploads/**` 和 `/uploads/resume/**` 静态映射，仅保留经 realpath 重叠检查的头像目录映射；头像目录与简历目录不能包含对方。简历上传校验 .pdf、`application/pdf`、`%PDF-` 文件头、5 MiB 大小；本人和投向本人岗位的 HR 使用经鉴权下载。旧附件以原路径保存，但静态直链失效，旧非 PDF 附件不会自动转换。M1 尚无历史文件快照，因此有投递引用的附件暂不允许替换或删除，避免主动破坏已有投递；对创建投递与替换附件的竞争还需 M3 事务/快照测试。

## 数据与版本

V001 基于锁定上游 schema 增量增加画像、城市、岗位类别、结构化条件、版本及邮箱验证标记。旧学历只读取最低 id 的有效默认简历，精确映射专科/大专=1、本科=2、硕士=3、博士=4，其他文本或无有效默认简历为 NULL；不猜测岗位薪资、应届资格、城市代码、分类或截止时间。旧邮箱验证情况未知，标记未验证。旧 `resume.education` 只作历史展示和迁移输入，画像是后续匹配来源。

岗位文本/条件更新和标签更新回待审并增版本；管理员批准必须提交所见版本，条件更新避免审核旧版本。岗位关闭与旧 remove 均只关闭，简历 delete 归档，旧管理员物理删除入口暂返回409。完整 ARCHIVED 状态、投递快照、历史事件、应用唯一键及关闭/投递并发事务均属于 M3。

数据库/service 的 LocalDateTime 采用 UTC，界面按 Asia/Shanghai 展示。上游历史 DATETIME 未记录时区，迁移前应确认来源；本合成库使用UTC，不对未知历史时间自动平移。
